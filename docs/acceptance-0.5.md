# 验收清单：设置页、小窗口下调、/strata 本地化（Windows，约 10–15 分钟）

验收的是 `main` 上尚未发版的改动（`package.json` 里的版本号仍是 0.4.1）。全程在 DeepSeek Harness 桌面版里操作，命令行步骤用 PowerShell。

**路径约定：** 下文的 `C:\Users\<you>\dsh-plugin-test` 是你的 Windows 测试文件夹，请换成你自己的实际路径（`<you>` 是你的 Windows 用户名）。把它作为本次验收的工作区打开。

---

## 0. 准备测试日志（PowerShell，约 1 分钟）

在 PowerShell 里运行（会在测试文件夹下生成 6 个各约 1500 行的日志）：

```powershell
$dir = "C:\Users\<you>\dsh-plugin-test\logs"
New-Item -ItemType Directory -Force $dir | Out-Null
1..6 | ForEach-Object { $d = $_; 1..1500 | ForEach-Object { "2026-11-0$d T$($_ % 24):00:00Z INFO worker-$($_ % 8) req=$([guid]::NewGuid()) latency=$(($_ * 7) % 997)ms bytes=$(($_ * 131) % 65536) status=200" } | Set-Content -Encoding utf8 "$dir\day$d.log" }
Get-ChildItem $dir
```

**预期：** 列出 `day1.log` … `day6.log`，每个约 130–150 KB。

## 1. 从 GitHub 重装插件（桌面版，约 2 分钟）

1. 桌面版左侧点 **插件** → 找到 **Strata 分层上下文** → 点进详情 → **卸载**（如已安装）。
2. 回到 **插件** 页，右上角 **添加插件**，在输入框填：

   ```
   github:light-cheng/DSH-Strata
   ```

   确认安装。

（命令行等价做法，在 PowerShell 里运行，`desktop` 是桌面版的 profile 名：
`dsh plugin --profile desktop add github:light-cheng/DSH-Strata`）

**预期：** 安装完成后插件列表里有 **Strata 分层上下文**，开关为开；详情页底部"来源信息"显示来自 GitHub。三个组件（Strata 分层上下文、Strata 预设接管、Strata 上下文工具）都显示"运行中"。如果提示需要重启，重启桌面版。

## 2. 设置页（桌面版，约 2 分钟）

1. **插件** → **Strata 分层上下文** 详情，往下滚到 **Strata 设置**。

   **预期：** 看到三块：
   - **模式**：成本优先 / 质量优先 / 自定义，默认选中"成本优先"，下面一行说明 50% / 60% / 30% / 末尾 10%；
   - **开关**：自动折叠（开）、提醒模型折叠（开）；
   - **存档**：存档位置（空，提示 `<DSH 主目录>/strata`）、大小提醒上限 `1024`、已结束会话的存档保留天数 `0`。

   每一项下面的说明都写着"立即生效"或"对新会话生效"。
2. 点 **自定义**。

   **预期：** 出现"自定义数值（仅在自定义模式下生效）"，有 4 个数字框和"轮中摘要""也折叠当前轮"两个开关。点回"成本优先"后这一块消失。
3. 为了几轮内就能看到自动折叠，选 **自定义**，填：自动折叠线 `5`，强制折叠线 `8`，折叠目标 `3`，受保护末尾上限 `2`。点 **保存**。

   **预期：** 按钮旁显示"已保存"，不需要重启。

## 3. /strata help 和 detail（对话里，约 2 分钟）

1. 在工作区 `C:\Users\<you>\dsh-plugin-test` 里 **新建会话**，先发一句：`只回复 OK，不要调用工具。`
2. 在输入框发送：

   ```
   /strata help
   ```

   **预期：** 中文帮助，比以前多一行 `/strata purge ended   清理已结束会话的归档（需要确认）`。
3. 发送：

   ```
   /strata detail
   ```

   **预期（第 1 节 概览）：**
   - `模式   自定义（设置页）`
   - `上下文窗口   1048.6K  (由服务商报告)`（DeepSeek 官方模型；若显示"默认值，服务商未报告"也算正常，只是窗口来自 1M 默认值）
   - `提醒模型折叠   开`
   - `本会话的本地存档`、`全部会话的存档   x.x MB，N 个会话（提醒上限 1024 MB）`、`存档位置   C:\Users\<you>\.dsh\strata`（或你的 DSH 主目录下的 strata）

   **预期（第 3 节 自动折叠）：**
   - `规则   轮末超过 5% 且连续 2 次提醒没有回应，或超过 8% 时，从最早的内容开始折叠……`
   - `官方摘要触发线   约 …K（…%）`，1M 窗口下在 60%–80% 之间，**没有**"已按窗口下调"字样
   - `上次轮末   跳过（x.x%，低于 5%）` —— 这一行现在是中文

## 4. 几轮读日志，看自动折叠（对话里，约 5 分钟）

在同一个会话里，**一轮发一条**，每条等模型答完再发下一条：

```
读取 logs\day1.log，用一句话说出里面有几行、status 都是什么。
```

```
读取 logs\day2.log，用一句话说出 latency 的大致范围。
```

```
读取 logs\day3.log，用一句话说出出现最多的 worker。
```

```
读取 logs\day4.log，一句话总结。
```

每轮之后可以发 `/strata status` 看占用。

**预期：**
- 上下文超过窗口的 8%（约 80K）后，那一轮结束时输入框下方的 Strata 指示会播放一次动画，文字显示 `自动折叠 T1 −xxK`。
- 再发 `/strata detail`：
  - 第 3 节 `上次轮末   已落地 f1（超过自动折叠线）` 或 `已落地 f1（强制）`（中文，不再是英文 `landed f1 …`）；
  - 第 2 节"其中自动折叠"大于 0；
  - 第 6 节有一行 `hh:mm:ss  自动折叠 T1  f1   −xxK`。
- 让模型回答 `day1.log 里第一行的 req 是什么？`，它应当用 `decompress` 或 `search_context` 找回原文，或者说明需要还原。

## 5. 切换模式立即生效（桌面版 + 对话，约 1 分钟）

1. 回到设置页，选 **质量优先**，**保存**。
2. 回到刚才的会话，发 `/strata detail`。

**预期：** `模式   质量优先（设置页）`；规则行变成 `轮末超过 25% … 或超过 35% 时 …；一轮中途超过 35% 时也会先摘要之前几轮`。不需要重启或新建会话。

## 6. 提醒开关（桌面版 + 对话，约 1 分钟）

1. 设置页把 **提醒模型折叠** 关掉，**保存**。
2. 会话里发 `/strata detail`。

**预期：** 概览里 `提醒模型折叠   关`。

## 7. 清理和恢复（约 1 分钟）

1. 会话里发 `/strata purge ended`。

   **预期：** 只给出说明和要删除的会话数、大小，最后一行是 `确定要删除，请发送：/strata purge ended confirm`；此时不删除任何文件。不想删就不要发 confirm。
2. 设置页点 **恢复默认**，按钮变成"确定恢复全部默认设置？"，再点一次。

   **预期：** 显示"已恢复默认"，模式回到"成本优先"，提醒开关回到开，存档项回到 空 / 1024 / 0。
3. 测试文件夹 `C:\Users\<you>\dsh-plugin-test\logs` 可以删除。

---

有任何一步和"预期"不一致，请把那一步的 `/strata detail` 输出（整段复制）和设置页截图发回来。
