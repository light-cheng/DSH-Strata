# 验收清单：设置页、拒收与最小收益门槛、官方摘要线、压缩行精简、/strata 本地化、状态栏白话与首次提示（Windows，约 15 分钟）

本次验收的是 `main` 上尚未发版的改动。`package.json` 里的版本号仍是 0.4.1，所以要用第 1 步的版本行确认装上的是哪个提交。全程在 DeepSeek Harness 桌面版里操作，用 DeepSeek 官方模型（1M 窗口），命令行步骤用 PowerShell。

**路径约定：**
- `C:\Users\<you>\dsh-plugin-test` 是你的 Windows 测试文件夹，请换成你自己的实际路径，`<you>` 是你的 Windows 用户名。把这个文件夹作为本次验收的工作区打开。
- 下文的 `<profile>` 是桌面版的 profile 名，一般是 `desktop`。

> 这份清单已在 Mac 上用临时 DSH 主目录完整跑过一遍。标了「Windows 待核对」的地方，Mac 上测不到，请你留意一下实际结果。

## 0. 准备测试日志（PowerShell，约 1 分钟）

在 PowerShell 里运行下面的命令。它会在测试文件夹下生成 6 个日志，每个约 1500 行：

```powershell
$dir = "C:\Users\<you>\dsh-plugin-test\logs"
New-Item -ItemType Directory -Force $dir | Out-Null
1..6 | ForEach-Object { $d = $_; 1..1500 | ForEach-Object { "2026-11-0$d T$($_ % 24):00:00Z INFO worker-$($_ % 8) req=$([guid]::NewGuid()) latency=$(($_ * 7) % 997)ms bytes=$(($_ * 131) % 65536) status=200" } | Set-Content -Encoding utf8 "$dir\day$d.log" }
Get-ChildItem $dir
```

**预期：** 列出 `day1.log` … `day6.log`，每个约 170 KB（`Length` 一列约 170000）。

## 1. 从 GitHub 重装插件，并核对版本（桌面版，约 2 分钟）

1. 桌面版左侧点 **插件** → 找到 **Strata 分层上下文** → 进入详情 → 如果已经安装，点 **卸载**。
2. 回到 **插件** 页，点右上角 **添加插件**，在输入框里填下面这行，然后确认安装：

   ```
   github:light-cheng/DSH-Strata
   ```

   命令行的等价做法：在 PowerShell 里运行 `dsh plugin --profile <profile> add github:light-cheng/DSH-Strata`。

3. 装完后如果提示需要重启，就重启桌面版。新建一个会话，发送 `/strata detail`，看第 1 节最上面一行。

**预期：**
- 插件列表里出现 **Strata 分层上下文**，开关是开的。详情页底部的「来源信息」显示来自 GitHub。
- 三个组件都显示「运行中」：Strata 分层上下文、Strata 预设接管、Strata 上下文工具。
- detail 第 1 节第一行类似下面这样：

  ```
  版本   0.4.1  ·  提交 xxxxxxx（GitHub 安装）  ·  代码 yyyyyyyy
  ```

  其中「提交」后面的 7 位号码，应当和主控告诉你的这次验收的提交号一致。
  - 如果显示的是「无提交号（npm 发布版）」，或者没有这一行，说明装上的不是 main 上的代码。那就停下来，把这一行发回来。

## 2. 设置页（桌面版，约 1.5 分钟）

1. 依次点 **插件** → **Strata 分层上下文** 详情，往下滚到 **Strata 设置**。

   **预期：** 看到三块：
   - **模式**：成本优先 / 质量优先 / 自定义，默认选中「成本优先」。下面有一句说明，提到 50% / 60% / 30% / 受保护末尾最多 10%。
   - **开关**：自动折叠（开）、提醒模型折叠（开）。
   - **存档**：存档位置（空，提示文字是 `<DSH 主目录>/strata`）、大小提醒上限 `1024`、已结束会话的存档保留天数 `0`。

   每一项下面的说明都写着「立即生效」或「对新会话生效」。
2. 点 **自定义**。

   **预期：** 出现「自定义数值（仅在自定义模式下生效）」，里面有 4 个数字框，还有「轮中摘要」「也折叠当前轮」两个开关。「也折叠当前轮」要先打开「轮中摘要」才能点。点回「成本优先」后，这一块消失。
3. 为了几轮之内就能看到自动折叠，选 **自定义**，按下表填写，然后点 **保存**：

   | 项 | 值 |
   |---|---|
   | 自动折叠线 | `5` |
   | 强制折叠线 | `8` |
   | 折叠目标 | `3` |
   | 受保护末尾上限 | `2` |
   | 轮中摘要 | **先不要打开**（第 5 步再开） |
   | 也折叠当前轮 | **先不要打开**（第 5 步再开） |

   **预期：** 按钮旁显示「已保存」，不需要重启。

## 3. 首次提示、状态栏、/strata help 和 detail（对话里，约 2.5 分钟）

1. 在工作区 `C:\Users\<you>\dsh-plugin-test` 里 **新建会话**，先发一句：`只回复 OK，不要调用工具。`

   **预期（首次提示，只出现这一次）：** 模型答完后，输入框下方 Strata 指示的上方弹出一个小气泡：`Strata 已在工作：当前是自定义。可以在 插件 → Strata 分层上下文 → Strata 设置 里调整。`，右边有「知道了」按钮。点「知道了」关掉。
   - 气泡不会出现在对话记录里，也不会发给模型。
   - 是否已提示记在 `C:\Users\<you>\.dsh\strata\state.json`（Windows 待核对：桌面版的 DSH 主目录可能不在这里）。如果这台电脑以前跑过本版本，文件已存在，就不会再弹；想重看，退出桌面版、删掉这个文件再打开。

   **预期（状态栏常驻一行）：** Strata 指示旁的文字是 `Strata · 上下文 x.x%，还没整理过`。把鼠标停在上面，弹出 3 行白话：`最近：还没有整理过。`、`现在：上下文用了约 x.x%（…K / 1000.0K）`、`下次：涨到约 5% 时先提醒模型折叠；提醒 2 次没回应，或涨到 8%，就在轮末自动整理`。
2. 发送：

   ```
   /strata help
   ```

   **预期：** 中文帮助，其中有一行 `/strata purge ended   清理已结束会话的归档（需要确认）`。
3. 发送：

   ```
   /strata detail
   ```

   **预期（第 1 节 概览）：**
   - 第一行是第 1 步看到的版本行。
   - `模式   自定义（设置页）`
   - `上下文窗口   1000.0K  (由服务商报告)`
     - 显示 `1048.6K`，或者显示「默认值，服务商未报告」，也算正常。
   - `提醒模型折叠   开`
   - `本会话的本地存档`
   - `全部会话的存档   x.x MB，N 个会话（提醒上限 1024 MB）`
   - `存档位置   …\strata`，是你的 DSH 主目录下的 strata 文件夹。

   **预期（第 3 节 自动折叠）：**
   - `规则   轮末超过 5% 且连续 2 次提醒没有回应，或超过 8% 时，从最早的内容开始折叠，直到约 …K（固定开销 + 剩余空间的 3%）`
     - 这一行**没有**「一轮中途」那半句，因为轮中摘要还没开。
   - `/strata help` 里 detail 那一行写着「分节详情（排错用）」。
   - `官方摘要触发线   约 550.5K（55%）`
     - DeepSeek V4 官方线路的数值是这个：1M 窗口减去 384K 的输出预留，再减去余量。
     - 换了别的模型或线路，数值可能不同，比如 68% 或 80%。
     - 这里**没有**「已按窗口下调」字样，因为 5% 和 8% 都低于它。
   - `上次轮末   跳过（x.x%，低于 5%）`
   - `上次失败   本进程内没有`
   - `上次拒收   本进程内没有`

## 4. 轮末自动折叠（对话里，约 3 分钟）

在同一个会话里一轮发一条，每条等模型答完再发下一条：

```
用 read 工具分段读完 logs\day1.log：offset 分别取 0、453、906、1359，各读一次，不要用 shell 统计。读完用一句话说出一共几行、status 都是什么。
```

```
同样用 read 分段读完 logs\day2.log（offset 0、453、906、1359），用一句话说出 latency 的大致范围。
```

（DSH 每次 read 最多返回约 450 行，大约 15–20K tokens，所以要分段读。每读完一轮，上下文大约涨 6–8%。）

每轮之后可以发 `/strata status` 看占用。

**预期：**
- 第 1 轮或第 2 轮结束时，上下文超过 8%，输入框下方的 Strata 指示会播放一次动画，文字显示 `自动折叠 T1 −xxK`。
- 动画过后（约 8 秒），文字变成白话行：刚落地时是 `Strata · 已整理 1 次，约 N 次请求后开始省`（净节省还是负的）；再发几轮后变成 `Strata · 本会话已省约 xxK（N 次整理）`。悬停看到 4 行：`最近：hh:mm 自动把 N 段较早的内容折成了摘要，腾出约 xxK`、`现在：…`、`下次：…`、`累计腾出约 xxK；「已省」按缓存价格折算…`。
  - 和 `/strata detail` 对一下：第 5 节的「已落地的变化」= 括号里的次数，「估算净节省」= 已省的数（为负时看「净节省转正 还需 ~N 次请求」= N），「累计回收」= 累计腾出；第 1 节「已用上下文」的百分比 = 「现在」那一行。
- 再发 `/strata detail`：
  - 第 3 节：`上次轮末   已落地 f…（超过自动折叠线）`，或 `已落地 f…（强制）`；
  - 第 2 节：「其中自动折叠」大于 0；
  - 第 6 节：有一行 `hh:mm:ss  自动折叠 T1  f…   −xxK`；
  - 成本一节如果写着「净节省为负」，属于正常：刚落地时会先重新计费一次，节省要在之后的请求里逐次累积回来。
- 让模型回答 `day1.log 里第一行的 req 是什么？`。它应当用 `decompress` 或 `search_context` 找回原文，或者说明需要先还原。

## 5. 一轮里多次大输出，看本轮折叠（对话里，约 2.5 分钟）

1. 回到设置页，在 **自定义** 下打开 **轮中摘要** 和 **也折叠当前轮**，点 **保存**。不需要重启。
2. 回到同一个会话，发下面这**一条**消息。只发一次，中途不要插话：

   ```
   用 shell 工具依次运行下面 4 条命令，每条单独调用一次工具，不要合并，也不要重复运行。全部运行完后，只用一句话告诉我：4 个文件里 latency 大于 900ms 的大约各有多少行。
   Get-Content "C:\Users\<you>\dsh-plugin-test\logs\day3.log"
   Get-Content "C:\Users\<you>\dsh-plugin-test\logs\day4.log"
   Get-Content "C:\Users\<you>\dsh-plugin-test\logs\day5.log"
   Get-Content "C:\Users\<you>\dsh-plugin-test\logs\day6.log"
   ```

   这 4 条命令是模型在对话里通过 shell 工具运行的，你不用自己去 PowerShell 里跑。路径要换成你的实际路径。Windows 上的工具名可能是 pwsh 或 PowerShell，属于「Windows 待核对」。

**预期：**
- DSH 会把每条命令的输出截在约 50K 字符，大约 15–20K tokens。运行 2–3 条之后，上下文超过 8%。在模型执行下一步之前，Strata 会先把本轮已完成的那几条命令的输出摘要掉，输入框下方的指示播放一次动画。
- 对话里的「上下文已压缩」行：**一次落地只有一行**，旧版是每折叠一段就一行。第 4 步和第 5 步加起来，一般只看到 2–4 行。
  - 点开其中一行，看到的是一句说明，大意是「Strata 整理了模型看到的上下文：折叠了 N 段较早的内容（f…），共 M 条记录，约 xxK tokens。这里的对话记录没有变……」。
  - 展开后**不应**再出现 archive 指针、「不是新指令」这类给模型看的文字。
  - 行上的标题「上下文已压缩」和副标题「已压缩 N 条历史记录（约 X tokens）」是 DSH 自己的固定格式，插件改不了。
  - 多段不相连的内容合成一行时，行上的「N 条」可能比展开后正文里的「共 M 条」少，这是 DSH 的限制，不算失败。
  - 用了子代理（fork）的会话里，父会话的压缩行会在子会话里再显示一遍，这也是 DSH 的行为，插件改不了。
- 模型对 day3～day6 **每条命令只运行一次**，不会重新运行 day3 或 day4。
  - 因为输出被截断，模型可能另外跑 1 次统计命令（比如数 latency），这不算重复。
  - 被摘要的那一段开头写着「这些调用已经运行过，需要原文用 `decompress` 或 `search_context` 还原」。
- 模型最后给出了一句回答，没有中途停下。
- 再发 `/strata detail`，看第 3 节：
  - `规则` 行末尾多了半句：`；一轮中途超过 8% 时也会先摘要之前几轮，再摘要本轮已完成的工具轮次`。
  - `轮中摘要   已落地 N 次（其中本轮 M 次）；最近：…`，要求 N ≥ 1 且 **M ≥ 1**。「最近」后面可能是后来的一次「跳过（…）」，这是正常的。
  - 第 6 节有对应的 `自动折叠` 记录。
- 同一份 detail 里，再看两行（只观察，不用制造失败）：
  - `上次失败   本进程内没有`。如果这一行有内容，它会写明时间、出错的层（`L1 切卡片` 或 `L2 折叠`）和原因，并注明输入框旁的图标因此变红。
  - `上次拒收`：可能是「本进程内没有」，也可能是一条记录。原因是中文，比如 `回收太少：只有约 …，低于每次至少 2.0K 的下限` 或 `不划算：要重新计费约 …，N 次请求后才回本…`。这表示有一次折叠被校验拦下了，**不算失败，图标不会变红**。如果这次拒收比最近一次落地晚，状态栏悬停的最后一行也会用同样的中文说一句「有一次…没做：…（校验拦下的，不算失败）」。
- 输入框下方 Strata 图标的颜色：
  - 平时是浅灰，折叠落地时播放浅蓝动画。
  - 红色只表示最近 10 分钟内有切卡片或折叠真的失败，文字是「切卡片失败」或「折叠失败」。
  - 灰色的「状态暂不可用」只是暂时读不到状态，不是压缩失败。
  - 红色、灰色和落地动画出现时，白话行让位，显示的是这几种状态的文字。
  - 如果看到红色或灰色，把截图或 detail 发回来即可。

## 6. 切换模式、提醒开关立即生效（桌面版加对话，约 1 分钟）

1. 回到设置页，选 **质量优先**，把 **提醒模型折叠** 关掉，点 **保存**。
2. 回到刚才的会话，发 `/strata detail`。

**预期：**
- 概览里显示 `模式   质量优先（设置页）` 和 `提醒模型折叠   关`。
- 规则行变成 `轮末超过 25% 时（提醒模型折叠已关，不等提醒），从最早的内容开始折叠，直到约 …；一轮中途超过 35% 时也会先摘要之前几轮，再摘要本轮已完成的工具轮次`。
  - 规则行里**不再**出现「连续 2 次提醒没有回应」：提醒关掉后，轮末一过自动折叠线就直接折叠，不等提醒。
- 状态栏悬停的「下次」一行跟着变：`下次：涨到约 25% 时，会在这一轮结束时整理；一轮中途超过 35% 也会先整理`（已超过 25% 时写 `已过整理线 25%…`）。
- `轮中摘要` 一行还在，次数和第 5 步一样。
- 不需要重启，也不需要新建会话。

## 7. 清理、恢复和重启（约 1.5 分钟）

1. 在会话里发 `/strata purge ended`。

   **预期：** 只给出说明，以及要删除的会话数和大小，最后一行是 `确定要删除，请发送：/strata purge ended confirm`。此时不会删除任何文件；不想删就不要发 confirm。如果还没有已经结束的会话，会显示 `没有可清理的已结束会话存档。`，这也正常。
2. 在设置页点 **恢复默认**。按钮会变成「确定恢复全部默认设置？」，再点一次。

   **预期：** 显示「已恢复默认」。模式回到「成本优先」，提醒开关回到开，三项存档设置回到 空 / 1024 / 0。
3. 回到会话，发 `/strata detail`，看第 3 节。

   **预期：** 成本优先下官方摘要线是 55%，比 60% 的强制折叠线低，所以两条线都被下调了。
   - 官方摘要线那一行是 `约 550.5K（55%）；已按窗口下调到 50%；两条线合并为一条，不再等提醒`。
   - 规则行只剩一条线：`轮末超过 50% 时，从最早的内容开始折叠，直到约 …K（…）`。
   - 规则行里**不再**出现「超过 50% … 或超过 50%」这种重复写法。
4. 完全退出桌面版，再重新打开，回到这个会话。

   **预期：** 会话能正常加载，不会出现「历史加载失败」或 `corrupt` 之类的提示。「上下文已压缩」的行数和数字都和退出前一样，任何一行的数字都不应是乱码。
   - 发一句 `只回复 OK。`：**不再**弹出第 3 步的首次提示气泡；新建一个会话再发一句，也不弹。
   - 状态栏文字是 `Strata · 上下文 x%，本次启动后还没整理`，悬停第一行写着「本次启动后还没有整理；对话里已有 N 个折叠…」。已省、次数和 detail 第 5、6 节一样，都只算本次启动以来的（设计如此）。
6. 可选：设置里把界面语言切到 English，悬停状态栏，内容应变成英文（`Strata · …`、`Last: …`、`Now: …`、`Next: …`）；`/strata detail` 的拒收原因也是英文。切回中文。
7. 测试文件夹 `C:\Users\<you>\dsh-plugin-test\logs` 可以删除。
