# DSH Strata

Strata 分层管理上下文：较早的工具输出切成卡片，较早的范围折叠成摘要，所有原文都留在本地存档里，被替换的内容不会丢。

- **工具卡片（L1）：** 每轮结束时，已完成的工具输出换成确定性卡片，保留错误、命令和退出码。不调用模型，前缀缓存照常命中。
- **最多三级折叠（L2）：** 模型用 `compress` 总结较早的范围，折叠还能再折叠（T1 → T2 → T3）。只有省下的 token 超过缓存损失、或上下文超过窗口 75% 时，折叠才落地。
- **自动摘要：** 模型不理会提醒时，Strata 在轮末自己折叠最早的内容，不调用模型（超过窗口 50% 且连续两次提醒没有回应，或超过 60%），直到上下文降到固定开销加剩余空间的约 30%。
- **本地存档（L3）：** `decompress` 逐级还原任意卡片或折叠，`search_context` 检索所有被替换的内容。
- **兜底：** 分层不够时 DSH 官方摘要照常运行；`strata_status` 和 `/strata` 显示当前状态。
- **设置：** 本页下方可选"成本优先 / 质量优先 / 自定义"模式、提醒开关和存档选项，保存后立即生效；只读信息看 `/strata detail`。

源码、问题反馈和发布说明：https://github.com/light-cheng/dsh-strata
